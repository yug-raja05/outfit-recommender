# 👕 Outfit Recommender
A simple Python-based outfit recommendation system that recommends outfits based on **color** and **occasion**.
## 📌 Project Description
The Outfit Recommender reads outfit information from a CSV file and recommends suitable outfits based on the user's selected color and occasion.
For example:
- Color: `Red`
- Occasion: `Party`
